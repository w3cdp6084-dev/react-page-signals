# Contributing

Thanks for helping improve `react-page-signals`.

## Before you start

- Open an issue before making a large change.
- Keep the package CSS-first and small.
- Avoid React state updates during scroll.
- Add or update tests when behavior changes.

## Local setup

```bash
pnpm install
pnpm dev
```

Before opening a pull request, run:

```bash
pnpm check
```

Use a short pull request description that explains the problem, the change, and
how you verified it.
